❓ Frequently Asked Questions by Kenyan Merchants

How do I register for WhaPay without internet?

Dial 0140933042 and follow the voice prompts. You'll receive your Member Code and QR via SMS. Or send an SMS with "REG YourName" to the same number.

Can I pay using M-Pesa if my phone has no data?

Yes. Use the merchant's Member Code (e.g., DK12345). Open M-Pesa → Lipa na M-PESA → Paybill → Enter Account = Member Code → Amount → PIN. No internet needed.

What are the fees for merchants?

No monthly fees, no setup fees. Only 1.5% + KES 20 per successful transaction. Free offline registration via voice/SMS.

How do I get a WhatsApp payment link?

After registration, we send your unique WhatsApp link. Share it with any customer – they click, choose M-Pesa or card, and pay in seconds.

Use WhaPay Even Without Internet

Register, pay, and complete transactions anytime — even offline. Perfect for low‑network areas.

Offline Registration

Two ways – no internet needed.

  • Voice Call: Dial 0140933042 → follow prompts → get Member Code & QR instantly.
  • SMS: Send REG YourName to 0140933042 → receive temporary code → activate via WhatsApp to get permanent Member Code + QR.

Offline Payment (Code)

Pay using merchant’s Member Code – no internet required.

  • Get merchant code (e.g., DK12345)
  • Open M-PESA → Lipa na M-PESA → Paybill/Till
  • Enter Account = Merchant Code, amount, PIN → Confirm
  • Both receive SMS – keep as proof
  • When online: send SYNC via WhatsApp to update dashboard

Printed QR Code

Display your QR – customers scan and pay offline.

  • Print your unique QR (sent after registration)
  • Customer scans with phone → sees merchant code + Till number
  • Opens M-PESA manually (no internet)
  • Pays using the details shown
  • SMS receipt saved; sync later via WhatsApp

💡 Why Offline Matters

With WhaPay, you are not limited by internet connection. Register via voice call or SMS, pay using M-PESA’s SMS network, and sync automatically when back online.
