  • SMS: Send REG YourName to +254705728896
  • Get temporary code → activate via WhatsApp

Offline Payment (Code)

Pay using merchant’s code – no internet required.

  • Customer gets merchant code (e.g., DK10245)
  • Go to M-PESA → Lipa na M-PESA → Paybill/Till
  • Enter Account = Merchant Code, amount, confirm
  • Both receive SMS – keep as proof
  • When online: send SYNC via WhatsApp to update balance

Printed QR Code

Display your QR – customers scan and pay, even offline.

  • Print your unique QR (sent after registration)
  • Customer scans with phone → sees merchant code + Till
  • Opens M-PESA manually (no internet needed)
  • Pays using the details shown
  • SMS receipt is saved; sync later via WhatsApp
