How WhaPay Works

Simple, step‑by‑step processes for registration, purchases, and merchant payments. Accept payments online or offline – no internet? Use Member Code with M‑Pesa.

📝 Registration Process

1️⃣ Choose method: Online (WhatsApp) or Offline (Voice/SMS)
↓
Online: Send REGISTER to +254710346425 (WhatsApp)
Offline Voice: Dial +254705728896 → follow prompts
Offline SMS: Send REG YourName to +254705728896 → get temporary code
↓
2️⃣ Provide name (user) or business name (merchant) + phone number
↓
3️⃣ System generates unique Member Code (e.g., DK12345) & QR
↓
✅ Registration complete – ready to transact

*Offline: voice call or SMS to +254705728896 – no internet needed.

🛍️ User Purchase Process

1️⃣ Customer scans merchant QR or gets Member Code
↓
2️⃣ Opens WhatsApp → sends PAY [CODE] [AMOUNT]
↓
3️⃣ WhaPay generates payment request (M-Pesa or card link)
↓
4️⃣ Customer clicks link → pays via M-Pesa STK Push or card
↓
5️⃣ Payment confirmation sent to both customer & merchant
↓
✅ Transaction recorded in dashboard – merchant receives money

*Offline alternative: Use M-PESA Paybill with merchant code as account number + SMS proof.

🏪 Merchant Process to Completion

1️⃣ Merchant registers (gets code & QR via WhatsApp, voice, or SMS)
↓
2️⃣ Shares QR / code with customers (in‑store or online)
↓
3️⃣ Customer initiates payment (see purchase process)
↓
4️⃣ Merchant receives instant WhatsApp notification (or SMS)
↓
5️⃣ Logs into live dashboard → views transaction history
↓
6️⃣ Generates weekly/monthly reports, tracks growth
↓
✅ Full payment lifecycle – from request to analytics

*Offline: merchant keeps SMS receipts, later syncs via WhatsApp command SYNC.

🔄 End‑to‑End Flow

Merchant registers (online or offline voice/SMS) → Customer pays via WhatsApp or offline M-PESA → Payment processed → Both receive confirmation → Merchant tracks in dashboard → Reports & insights for growth

Use WhaPay Even Without Internet

Register via voice call or SMS, pay using Member Code – no internet required.

Offline Registration

Two ways – no internet needed.

  • Voice Call: Dial +254705728896 → follow prompts (name/phone) → get Member Code & QR instantly.
  • SMS: Send REG YourName to +254705728896 → receive temporary code → activate via WhatsApp to get permanent Member Code + QR.
📞 Call 📱 Send SMS

Offline Payment (Code)

Pay using merchant’s Member Code – no internet required.

  • Get merchant code (e.g., DK12345)
  • Open M-PESA → Lipa na M-PESA → Paybill/Till
  • Enter Account = Merchant Code, amount, PIN → Confirm
  • Both receive SMS – keep as proof
  • When online: send SYNC via WhatsApp to update dashboard

Printed QR Code

Display your QR – customers scan and pay offline.

  • Print your unique QR (sent after registration)
  • Customer scans with phone → sees merchant code + Till number
  • Opens M-PESA manually (no internet)
  • Pays using the details shown
  • SMS receipt saved; sync later via WhatsApp

💡 Why Offline Matters

With WhaPay, you are not limited by internet connection. Register via voice call or SMS, pay using M-PESA’s SMS network, and sync automatically when back online.
