Offline Payment (Code)

Pay using merchant’s code – no internet required.

  • Customer gets merchant code (e.g., DK10245)
  • M-PESA → Lipa na M-PESA → Paybill/Till
  • Enter Account = Merchant Code, amount, confirm
  • Both receive SMS – keep as proof
  • When online: send SYNC via WhatsApp

Printed QR Code

Display your QR – customers scan and pay, even offline.

  • Print your unique QR (sent after registration)
  • Customer scans → sees merchant code + Till
  • Opens M-PESA manually (no internet)
  • Pays using the details shown
  • SMS receipt saved; sync later via WhatsApp
