Use WhaPay Even Without Internet

Register, pay, and complete transactions anytime — even offline. Perfect for low‑network areas.

Offline Registration

Register without internet – via SMS or WhatsApp.

  • SMS: Send REG Your Name to +254705728896
  • WhatsApp: Send "REGISTER" to +254710346425 (may require internet)
  • You receive a Temporary Code (e.g., TMP5821)
  • When online: send ACTIVATE TMP5821 via WhatsApp
  • Get permanent Member Code + QR via WhatsApp/SMS

Offline Payment (Code)

Pay using merchant’s code – no internet required.

  • Customer gets merchant code (e.g., DK10245)
  • Go to M-PESA → Lipa na M-PESA → Paybill/Till
  • Enter Account = Merchant Code, amount, confirm
  • Both receive SMS – keep as proof
  • When online: send SYNC via WhatsApp to update balance

Printed QR Code

Display your QR – customers scan and pay, even offline.

  • Print your unique QR (sent after registration)
  • Customer scans with phone → sees merchant code + Till
  • Opens M-PESA manually (no internet needed)
  • Pays using the details shown
  • SMS receipt is saved; sync later via WhatsApp

💡 Why Offline Matters

With WhaPay, you are not limited by internet connection. Register, pay, and run your business anytime, anywhere – using M-PESA’s SMS network. Sync automatically when back online.
