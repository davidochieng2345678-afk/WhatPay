WhaPay Process Flows

Simple, step‑by‑step diagrams for registration, user purchase, and merchant flow

📝 Registration Process

1️⃣ User / Merchant opens WhatsApp
↓
2️⃣ Sends REGISTER to WhaPay number
↓
3️⃣ Provides name & phone number
↓
4️⃣ System generates unique Member Code
↓
5️⃣ Receives code + QR via WhatsApp
↓
✅ Registration complete – ready to pay or receive

*Also available offline via USSD *789# (coming soon)

🛍️ User Purchase Process

1️⃣ Customer scans merchant QR or gets Member Code
↓
2️⃣ Opens WhatsApp → sends PAY [CODE] [AMOUNT]
↓
3️⃣ WhaPay generates payment request (M-Pesa or card link)
↓
4️⃣ Customer clicks link → pays via M-Pesa STK Push or Stripe card
↓
5️⃣ Payment confirmation sent to both customer & merchant
↓
✅ Transaction recorded in dashboard – merchant receives money

*Offline: use M-PESA Paybill with merchant code + SMS proof

🏪 Merchant Process to Completion

1️⃣ Merchant registers (gets code & QR)
↓
2️⃣ Shares QR / code with customers (in‑store or online)
↓
3️⃣ Customer initiates payment (see purchase process)
↓
4️⃣ Merchant receives instant WhatsApp notification
↓
5️⃣ Logs into live dashboard → views transaction history
↓
6️⃣ Generates weekly/monthly reports, tracks growth
↓
✅ Full payment lifecycle – from request to analytics

*Offline: merchant records SMS and syncs later via WhatsApp command SYNC

🔄 End‑to‑End Flow

Merchant registers → Customer pays via WhatsApp → Payment processed (M-Pesa/card) → Both receive confirmation → Merchant tracks in dashboard → Reports & insights for growth
