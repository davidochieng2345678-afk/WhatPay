How WhaPay Works

Simple, step‑by‑step processes for registration, purchases, and merchant payments. Accept WhatsApp payments in Kenya with ease.

📝 Registration Process

1️⃣ User / Merchant opens WhatsApp
↓
2️⃣ Sends REGISTER to WhaPay number
↓
3️⃣ Provides name & phone number
↓
4️⃣ System generates unique Member Code
↓
5️⃣ Receives code + QR via WhatsApp
↓
✅ Registration complete – ready to pay or receive

*Also available offline via USSD *483# (coming soon)

🛍️ User Purchase Process

1️⃣ Customer scans merchant QR or gets Member Code
↓
2️⃣ Opens WhatsApp → sends PAY [CODE] [AMOUNT]
↓
3️⃣ WhaPay generates payment request (M-Pesa or card link)
↓
4️⃣ Customer clicks link → pays via M-Pesa STK Push or Stripe card
↓
5️⃣ Payment confirmation sent to both customer & merchant
↓
✅ Transaction recorded in dashboard – merchant receives money

*Offline: use M-PESA Paybill with merchant code + SMS proof

🏪 Merchant Process to Completion

1️⃣ Merchant registers (gets code & QR)
↓
2️⃣ Shares QR / code with customers (in‑store or online)
↓
3️⃣ Customer initiates payment (see purchase process)
↓
4️⃣ Merchant receives instant WhatsApp notification
↓
5️⃣ Logs into live dashboard → views transaction history
↓
6️⃣ Generates weekly/monthly reports, tracks growth
↓
✅ Full payment lifecycle – from request to analytics

*Offline: merchant records SMS and syncs later via WhatsApp command SYNC

🔄 End‑to‑End Flow

Merchant registers → Customer pays via WhatsApp → Payment processed (M-Pesa/card) → Both receive confirmation → Merchant tracks in dashboard → Reports & insights for growth

Use WhaPay Even Without Internet

Register, pay, and complete transactions anytime — even offline. Perfect for low‑network areas.

Offline Registration

Register without internet – via SMS or WhatsApp.

  • SMS: Send REG Your Name to +254705728896
  • WhatsApp: Send "REGISTER" to +254710346425 (may require internet)
  • You receive a Temporary Code (e.g., TMP5821)
  • When online: send ACTIVATE TMP5821 via WhatsApp
  • Get permanent Member Code + QR via WhatsApp/SMS

Offline Payment (Code)

Pay using merchant’s code – no internet required.

  • Customer gets merchant code (e.g., DK10245)
  • Go to M-PESA → Lipa na M-PESA → Paybill/Till
  • Enter Account = Merchant Code, amount, confirm
  • Both receive SMS – keep as proof
  • When online: send SYNC via WhatsApp to update balance

Printed QR Code

Display your QR – customers scan and pay, even offline.

  • Print your unique QR (sent after registration)
  • Customer scans with phone → sees merchant code + Till
  • Opens M-PESA manually (no internet needed)
  • Pays using the details shown
  • SMS receipt is saved; sync later via WhatsApp

💡 Why Offline Matters

With WhaPay, you are not limited by internet connection. Register, pay, and run your business anytime, anywhere – using M-PESA’s SMS network. Sync automatically when back online.
